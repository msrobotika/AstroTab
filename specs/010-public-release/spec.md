## Escenarios y criterios de aceptación

- A1 / P1: una persona puede compilar y probar app y core desde una copia nueva con JDK 17 y Android SDK 36. `testDebugUnitTest lintDebug assembleDebug` termina correctamente en el destino.
- A2 / P1: el árbol versionado no contiene identidad privada, rutas personales, redes domésticas, direcciones privadas, identificadores de hardware ni direcciones de contacto. Las pruebas del lugar privado se sustituyen por Madrid; los resultados astronómicos se recalculan y se conserva evidencia del cálculo.
- A3 / P1: el origen permanece intacto, acreditado con hashes anteriores/posteriores. La selección excluye cachés, builds, copias, registros, inspecciones, capturas y planes internos. Conserva código, recursos, wrapper, licencias y Markdown de especificaciones.
- A4 / P2: README español con resumen inglés describe funciones reales, límites, instalación, compilación, privacidad por servicio, créditos, HOME y kiosco con recuperación. Incluye siete espacios de imágenes con texto alternativo; CONTRIBUTING, plantilla de bug y ROADMAP útiles.
- A5 / P1: un único commit inicial en main con identidad pública solicitada, sin remotos ni publicación. El informe final muestra carpetas, tamaño, pruebas y búsqueda de privacidad mediante git grep.

## Aclaraciones resueltas

Las instrucciones de instalación son documentación: no autorizan ejecutar comandos sobre dispositivos. La identidad pública del commit es la excepción explícita a la prohibición de contactos; no se escribe en archivos versionados. Los certificados de prueba son públicos o sintéticos; la clave TLS de localhost solo sirve a pruebas de loopback. No se incluyen capturas previas ni el boceto interno. La licencia del código propio continúa siendo MIT; el carácter no comercial describe el proyecto y el uso de servicios, sin reescribir MIT.

## Casos límite

Los números del catálogo y los vectores orbitales no representan ubicaciones del autor. Las evidencias históricas saneadas no acreditan una ejecución nueva. No se promete validación física de esta copia.
