# Constitución pública de AstroTab

Versión 2.0.0 · 2026-11-06 · AstroTab 0.7.1 · especificación activa 010-public-release.

1. Segunda vida para tablets Android 6+, sin cuenta ni Google Play Services. Astronomía y catálogos offline; ubicación manual sin valor ficticio, brújula y GPS innecesarios.
2. Privacidad: red desactivada por defecto y revocable; proveedores y datos enviados documentados. Ninguna información personal, rutas locales, redes domésticas o coordenadas privadas en el repositorio. Las ubicaciones de pruebas representan ciudades públicas.
3. Kotlin y View/Canvas con núcleo JVM comprobable. Mantener fórmulas, procedencia, atribuciones y límites de precisión; no confundir estimaciones con medidas.
4. Evidencia honesta: registrar pruebas reales y distinguir simulación Android de hardware. No atribuir a la copia pública validaciones físicas anteriores.
5. Código propio MIT, MS Robotika. Proyecto abierto y no comercial; conservar licencias de terceros sin añadir restricciones a MIT.
6. Aplicar GitHub Spec Kit antes de mejorar software: especificación, aclaraciones materiales, plan, tareas, checklist, coherencia, implementación y contraste de criterios. Para bugs: diagnóstico, reparación y verificación del síntoma. Proteger la base y no instalar extensiones ni delegar automáticamente.
7. Esta preparación solo modifica la copia pública: sin dispositivos, instalación del sistema, remotos ni publicación; red solo Gradle/Maven. Se autoriza preparar el repositorio y crear un único commit inicial local. La documentación de instalación no concede permiso para usar hardware.

Spec Kit aplicado manualmente con sus plantillas oficiales locales, sin CLI disponible. Los Markdown históricos se conservan saneados como contexto; las evidencias de esta preparación están en specs/010-public-release/verification.md y prevalecen sobre historiales.
